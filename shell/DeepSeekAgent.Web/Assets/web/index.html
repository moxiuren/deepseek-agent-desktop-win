token
怎么拿：浏览器打开 chat.deepseek.com 并登录 → F12 → Console → 输入 localStorage.getItem('userToken') 回车 → 把整段结果（含花括号）复制过来即可，程序会自己解析（裸串 / 带引号 / 带 Bearer 前缀都吃得下）。 保存后程序会验一次：验证不通过会明确告诉你，不会假装成功。
